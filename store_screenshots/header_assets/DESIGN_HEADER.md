# App Store「ヘッダ／検索結果」デザイン素案

5244×2950px・不透明PNGの共通原稿を1枚制作する。仕様・禁止表現は今回の依頼条件に準拠。添付のLP画像とストア画像、`ref_screenshot_design.md`を参照。画像制作・HTML実装は本書の対象外。

## 1. 方向性

| | A：日本の「いま」が光る（推奨） | B：手元から、全国へ |
|---|---|---|
| 狙い | 実在するカメラの広がりを、光点でできた日本列島として記憶させる。LPとの連続性をつくる | 氷青の既存スクリーンショットとつなぎ、地図から探せる実用性を伝える |
| 構図 | 中央上部に日本列島、中央下部に短いコピー。端まで広がる暗い余白 | 中央の左に2行コピー、右に直立した端末1台。背後に淡い等高線 |
| 色 | 背景 `#050B13`、中心の紺 `#10243B`、点 `#8DCBFF`／`#B3F0ED`、文字 `#EDF3FF` | 背景 `#F3FAFD`→`#D5EAF3`、文字 `#102E49`、強調 `#1E6FD9`、等高線 `#B6D6E5` |
| 書体 | Dela Gothic One、400。LPの見出しを継承。明朝・英字書体は追加しない | Noto Sans JP、900。既存ストア素材を継承 |
| コピー | **日本の今を、地図で。**（10文字、1行） | **近くの今を、／地図で。**（／は改行、計10文字） |
| 端末 | 使用しない | iPhoneの既存フレーム1台。既存2枚目に使う「地図画面」を使用。カメラのピンと選択地点のプレビューが見える実画面。詳細画面・台風画面は使わない |
| 21:9 | 上下の余白が減り、列島とコピーが横長の中央にまとまる | 左のコピーと右の端末が残る。端末は上下を切らず収める |
| 3:2 | 左右の余白が減り、列島がカードの主役になる | 左右の装飾が消え、コピーと端末の組だけが残る |

Bの目安：コピー枠 `(950, 1090, 1720, 850)`、文字340px・行高1.2。端末枠 `(2980, 650, 850, 1732)`、回転0度。座標は左上x・y・幅・高さ。実画面の比率を保ち、地図の出典は隠さない。コピー以外の補助文・数字・チップは置かない。

## 2. 推奨Aの制作指定

**採用理由：** 端末内の細かなUIを読ませずに全国性を伝えられる。既存の明るいスクリーンショットと役割を分けつつ、LPの光点地図をブランドの共通要素にできる。

### キャンバスとガイド

原点は左上。すべて原寸px、中央基準でトリミングする想定。

| ガイド | x | y | 幅 | 高さ |
|---|---:|---:|---:|---:|
| 原稿 | 0 | 0 | 5244 | 2950 |
| 21:9表示の目安 | 0 | 351.3 | 5244 | 2247.4 |
| 3:2表示の目安 | 409.5 | 0 | 4425 | 2950 |
| 保守的な共通セーフエリア | 630 | 384 | 3984 | 2182 |
| 重要要素用の内側枠 | 850 | 540 | 3544 | 1880 |

比率から算出した3:2の左右カットは各約7.8%。今回は依頼の左右約12%を保守的な基準として採用し、上下各約13%との交差領域を共通セーフエリアにする。これは制作ガイドであり、Apple公式のセーフエリア保証ではない。

確認モードのみ、共通枠に6px破線 `#FF4D99`、内側枠に4px実線 `#FFD36A` を表示。枠線は内側に描画し、書き出し時は両方とも非表示。

### 配置・描画（背面から順）

| 要素 | 指定 |
|---|---|
| 背景 | 全面 `#050B13`、不透明。中心 `(2622, 1320)` に横半径1900・縦半径1100pxの楕円グラデーション。中心 `#10243B`、外端で背景色へ。地図の背後だけに穏やかな明るさをつくる |
| 地図 | 外接枠 `(1150, 620, 2944, 1420)`。国内の既存承認済みカメラ座標を読み取り、北を上にした同一投影・等倍率で枠内中央に収める。北海道〜沖縄・離島を含め、回転・縦横別拡大・離島の移動はしない。枠はクリップ領域ではなく収容領域 |
| 光点 | 基本の直径5px、`#8DCBFF`、不透明度0.65。密集箇所は直径3px・不透明度0.4に抑え、白い塊を避ける。重なりは通常のアルファ合成。固定IDのハッシュで選ぶ約5%の点だけ直径8px・`#B3F0ED`・不透明度0.9とし、その背後に半径18pxの薄い放射グラデーション（中心色の不透明度0.2→0）を置く |
| コピー | 枠 `(850, 2110, 3544, 310)`。中央揃え、Dela Gothic One 400、**250px**、行高**310px（1.24）**、字間0。`日本の今を、地図で。`を改行せず表示。色 `#EDF3FF`、最後の「地図で。」のみ `#A4E3EE`。影・縁取り・文字の光彩なし |

文字と地図を重ねない。光点はカメラ位置を示すブランド表現であり、点の明るさで稼働状態や警報を表現しない。架空の座標を足して列島を埋めない。全国形状の識別が弱ければ、まず点の径・濃度を調整する。

地図はLPの元の座標描画処理・素材を優先して再利用する。完成済み `ref_lp_og.png` の拡大流用は避ける（文字が重なり、低解像度で、禁止表現も含まれるため）。新しい地図タイルの取得やカメラ画像の収集は不要。元処理がなければ既存台帳の座標から描画し、台帳は変更しない。

### 実装・確認

- HTMLのルートを5244×2950px、`overflow: hidden`、背景不透明に固定。SVGまたはCanvasで光点、CSSで背景・文字を描画する。画像生成AIは使用しない。
- フォントはローカルに固定し、`document.fonts.ready`と地図描画完了後にPlaywrightで撮影。`deviceScaleFactor: 1`。アニメーション・非固定乱数を使わない。
- 原寸PNGは5244×2950px、sRGB、アルファなしのRGBにする。ガイド・デバッグ文字が混入していないことを確認。
- 原稿と、中央21:9／3:2のクロップを確認する。さらに左右12%・上下13%を同時に隠す厳しめの確認を行い、地図全体とコピーが残ることを見る。
- 幅390pxの両クロップでも確認。コピーは約19〜22px相当。列島がひと目で分かり、密集部が白く潰れないこと。提出前にApp Store側の実プレビューでも位置・重なりを確認する。

## 3. 避けること・審査上の注意

- 価格、「無料」「登録不要」、割引、URL、©、受賞・ランキング表現、他プラットフォームの名称やロゴ、Appleのバッジは入れない。参考画像の「FREE」「iOS / ANDROID」「無料・登録不要」は引き継がない。
- アプリ名・台数・機能一覧・英文ラベル・REC表示・四隅の飾り枠を追加しない。細かな格子、走査線、強いネオン、照準風の円も省く。文字は指定コピーだけ。
- 全地点が常時動画配信・リアルタイム更新していると保証する表現、行政公式アプリに見える紋章、「必ず安全」「逃げ遅れない」などの安全保証は使わない。
- 被災者、事故、氾濫の衝撃映像、架空の警報・通知で不安をあおらない。年齢区分4+相当の穏やかな地図表現とする。
- Bに変更する場合も実画面を使用し、機能や地点を捏造しない。カメラ画像・地図・端末素材のプロモーション用途の利用条件を確認し、必要な出典を切らない。出典が収まらない素材は選ばない。
- 本書は依頼された素材仕様での設計。提出時はApp Store Connectに表示される最新の素材要件と照合する。

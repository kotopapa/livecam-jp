プライバシーポリシー

「全国ライブカメラ地図」（以下「本アプリ」）は、利用者のプライバシーを尊重し、個人情報の取り扱いについて以下のとおり定めます。

1. 収集する情報

本アプリは、利用者を識別できる個人情報（氏名・メールアドレス・電話番号等）を収集しません。アカウント登録もありません。

2. 位置情報の利用

本アプリは、現在地周辺のカメラ表示・距離順の並べ替えのために、利用者の許可を得た場合に限り端末の位置情報を利用します。位置情報は端末内でのみ処理され、開発者や第三者のサーバーへ送信・保存されることはありません。位置情報の利用は端末の設定からいつでも無効にできます。

3. 通信先について

本アプリは動作のために以下の外部サービスと通信します。それぞれの通信には各運営者のプライバシーポリシーが適用されます。

  • GitHub Pages（カメラ一覧などの配信データの取得）
  • 国土地理院 地理院タイル（地図の表示）
  • YouTube（Google）（ライブ映像の埋め込み再生）
  • 各カメラ提供元のサーバー（カメラ画像の取得。国土交通省・自治体・放送局・民間事業者等）

4. お気に入り等の設定情報

お気に入り登録・アプリ内の設定は端末内にのみ保存され、外部へ送信されません。

5. 広告について

現在、本アプリは第三者配信の広告を掲載していません。将来、広告配信を導入する場合は、導入前に本ポリシーを更新し、広告事業者が取得する情報について明記します。

6. お問い合わせ

本ポリシーに関するお問い合わせは、ご相談・依頼フォーム（ログイン不要）または GitHub Issues までお願いします。

7. 改定

本ポリシーは必要に応じて改定されることがあります。重要な変更がある場合は本ページで告知します。

# 沖縄・離島ライブカメラ 調査（2026-09-03）

ユーザー指摘「沖縄、特に離島のカメラがほぼない」。先島諸島と本島周辺離島・大東・本島の空白地域を2調査で当たった。
取り込みは scratchpad の `okinawa/merge_okinawa.py`（消えたら本文書を元に再作成）: 候補JSON → 重複排除 → 検証（YouTube: isLiveNow/oEmbed、チャンネル型: /live の存在、静止画: image/* かつ非0バイト）
→ 市町村名を JIS コードへ変換 → `curated_youtube.yaml` / `curated_still.yaml` と `data/cameras.json` に追加。note に「既存の差替え」と明記された候補は新規追加ではなく既存枠の更新（チャンネルID化）。

## 結果
- 沖縄 107 → **132台**（+25、うち石垣3・竹富1・宮古1・久米島2・伊江3・東村6・本部1・今帰仁1・北谷1・名護3・那覇3）
- 既存の**配信ID切替に追従 10枠**: 石垣島730交差点・ユーグレナ離島ターミナル・舟蔵ビーチ・石垣空港FI・YAEYAMA LIVE（→チャンネルID化）、KIN-TAKA 4本、琉球新報（国際通り・県庁前に改名）
- 既存「小浜島」（YAEYAMA LIVE 旧枠）は実際は石垣島名蔵湾・フサキビーチの映像だったため改名・座標修正
- 二重登録の解消 2件（KIN-TAKA の `curated-lcdb-*` 重複を退役）

## 見送り・注意
- **ライブカメラ24（livecamera24.jp）系 7本**（糸満西崎・うるま州崎・那覇識名・首里・与那原×2・南風原）: 店舗等に設置する事業者のYouTube定点カメラだが運営会社名を確認できず見送り。運営者が特定できれば追加候補
- 運営者不明のチャンネル（ミーバルビーチcam・古宇利島ちゃんねる・砂辺メイン）は見送り
- 東村防災カメラは村HPの一般的な著作権表記のみ（転載禁止文言なし）→ 静止画を直接表示（10秒更新のところ60秒で取得）
- とまりん港LIVEカメラ（泊ふ頭開発）は Panasonic BB-ST162 の SnapshotJPEG。公式ページからリンクされているので採用（閲覧者操作のPTZで向きが変わる）
- 海上保安庁 十一管区の灯台カメラは既存5台で全て（API `camportalAPI/camera/getlist` で確認）。「海の安全情報」利用規約は出典明記で複製・公衆送信可（https://www6.kaiho.mlit.go.jp/info/mics_terms.html）
- 沖縄県河川情報システムの未登録カメラ（天願川・大井川・満名川等）は「調整中」プレースホルダ、または2024年の固定画像 → 新規なし
- 下地島空港・宮古島市・石垣市・竹富町・与那国町・多良間村・沖縄総合事務局（平良・石垣港湾）・航路会社に公開カメラなし
- live.arksystem.jp（崎枝・やえやまファーム）は「無断リンク・無断使用は固くお断り」かつ非配信 → 不採用

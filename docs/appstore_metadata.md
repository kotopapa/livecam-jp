```
日本全国 約15,000台のライブカメラを、地図から無料でまとめて見られるアプリです。会員登録は不要。国土交通省「川の防災情報」や各自治体・放送局などが公開している河川・道路・海岸・火山のカメラを、現在地周辺からワンタップで確認できます。

■ こんなときに使えます
・台風や大雨のとき、近所の川がどうなっているか見たい
　→ 全国約11,500台の河川カメラを地図から。水位が心配な川の「今」を自分の目で確認できます。
・雪道や峠を運転する前に路面状況を知りたい
　→ 国道・県道の道路カメラ約2,600台。積雪や凍結の様子を出発前にチェック。
・海に行く前に波や混雑を見たい
　→ 海岸・港のカメラで波の高さやビーチの様子がわかります。サーフィン・釣りの下見にも。
・地震や津波のニュースを見て現地の様子が気になる
　→ 災害速報タブで最新の地震・津波・気象警報を確認し、そのエリアのカメラ一覧へすぐ移動できます。
・旅行先や帰省先の天気・混雑を出発前に見たい
　→ 渋谷スクランブル交差点、富士山、桜島など、景勝地・都市のライブ映像も多数収録。

■ 主な機能
・地図表示: 全国のカメラをカテゴリ別の色分きピンで表示。現在地周辺・都道府県ジャンプ・地名検索に対応
・ライブ映像: YouTube公式配信のカメラは動画をそのまま再生。静止画カメラは最新画像を自動取得
・災害速報: 地震・津波・気象警報を一覧表示し、発生エリアの周辺カメラへワンタップで移動

・絞り込み: 河川・道路・海岸・火山・ダム・景観などカテゴリや「映像のみ」で表示を絞れます

国土交通省「川の防災情報」・「道路情報提供システム」、都道府県・市町村の公開カメラ、放送局や民間事業者の公式YouTubeライブ配信など、運営元が公開しているカメラのみを人手で確認して掲載しています。すべてのカメラに出典を明記し、掲載をやめてほしい運営者さまからの削除依頼窓口（アプリ内・ログイン不要のフォーム）を設けています。

## 審査メモ（App Review情報 → メモ欄に貼り付け）

```
【アプリ概要】
日本全国の官公庁・自治体・放送局等が「公開」しているライブカメラ約15,000台を地図から閲覧できるアプリです。

【コンテンツの権利について】
・掲載カメラはすべて、運営元がウェブで一般公開しているものです。1台ずつ人手で確認し、出典（運営者名・元ページへのリンク）をアプリ内の詳細画面に明記しています。
・YouTubeの映像は、YouTube公式のIFrame埋め込み（利用規約準拠）でのみ再生し、映像データの複製・再配信は行っていません。
・静止画カメラは各運営元のサーバーから直接取得して表示しており、当方のサーバーで映像を中継・保存することはありません。
・運営者からの削除依頼を受け付ける窓口（ログイン不要のGoogleフォーム）をアプリ内とWebサイトに設置しており、依頼があれば速やかに削除します。

【テストについて】
・ログイン不要で全機能を利用できます。テストアカウントは不要です。
・位置情報の許可はスキップ可能です（許可しない場合も全機能利用可）。
・プッシュ通知は震度5弱以上の地震・特別警報の発表時のみ送信されるため、審査中に受信できない場合があります。設定画面の「災害通知」でON/OFF箇所をご確認いただけます。

【連絡先】
不明点があれば App Review 連絡先までご連絡ください。日本語・英語どちらでも対応します。
```

## スクリーンショット（ユーザー作業）

必須: 6.9インチ（iPhone 17 Pro Max等）。6.5インチは6.9から自動流用可。
推奨構成（左から）:
1. 地図画面（ピンが全国に広がっている引きの図）＋キャッチ「全国約15,000台を地図から」
2. 詳細画面（河川カメラの画像＋出典表示）＋「川の"今"を自分の目で」
3. 道路カメラ（雪道）＋「出発前に路面チェック」
4. 災害速報タブ＋「地震・津波・警報をすぐ確認」
5. ランキング or お気に入り＋「よく見るカメラをまとめて」
シミュレータでの撮影: iPhone 17 Pro Max で ⌘S（デバイスベゼル無しの生画面でOK）

## 申請の手順（App Store Connect）

1. マイApp → 対象App → 「App情報」: 名前・サブタイトル・カテゴリを設定
2. 「価格および配信状況」: 無料・全地域（または日本のみ）
3. 「Appのプライバシー」: 上表の2項目を回答して公開
4. バージョン情報ページ: 説明文・キーワード・プロモーションテキスト・スクリーンショット・サポートURLを入力
5. ビルド欄で 1.0.0(6) を選択（TestFlightに上がっているもの）
6. App Review情報: 審査メモを貼り付け、連絡先を入力
7. 「審査へ提出」。初回審査は通常1〜3営業日
8. 承認後: App StoreのURLが確定したら site/build.py の STORE_URL に設定（強制アップデート誘導が有効化される）

# 自治体の災害情報 X アカウント調査（2026-09-06）

カメラ詳細や防災タブから、その地域の自治体の災害情報アカウントへ誘導する構想の調査。

## 結論（設計に影響する3点）

### 1. アプリ内でのポスト表示は現実的でない → リンクのみにする
- **X API は2026年2月に従量課金へ移行し無料枠が廃止**。読み取り $0.005/件。利用者がタイムラインを開くたびに課金され費用が読めない
- **埋め込みタイムライン**は2023年以降不安定で、未ログイン閲覧では表示されないことが多い（2026年時点で未解決）
- プロフィールページ自体はログイン無しで開けるので、**外部ブラウザでアカウントを開く導線**なら追加費用ゼロで成立する

### 2. アカウントの実在・内容は機械的に検証できる
`x.com/<handle>` は未ログインでも `<title>`（表示名）と og:description（プロフィール本文）を返す。
存在しなければ404。検証スクリプトは `xverify.py`（本ディレクトリ）。

### 3. ハンドル名の推測だけでは危険（必ず本文で公式性を確認する）
自動探索で紛らわしい非公式アカウントが多数見つかった。防災アプリが誤って案内すると重大な問題になる。

| ハンドル | 実際の中身 |
|---|---|
| `hokkaido_bousai` | 北海道支店 防災・鉄構（民間企業） |
| `ibarakibousai` | 茨城県の防災士会（仮）「非公認のアカウントです」 |
| `akita_saigai` | 通りすがりのアルパカ（無関係） |
| `Chiba_Bousai` | 防災士個人 |
| `yamagatabousai` | 山形**市**防災対策課（県ではない） |
| `bousai_aomori` | 「青森県防災」を名乗るがフォロワー0の休眠 |

**採用条件**: プロフィール本文に「公式」＋当該自治体の部署名（危機管理課・防災局等）が明記されていること。
フォロワー数が極端に少ないものは休眠・なりすましを疑う。

## 運営主体の種別を必ず併記する（2026-09-06 ユーザー決定）
アカウントを除外せず、**運営主体の種別を付けて一覧に載せる**。アプリ表示時も必ず併記して誤認を防ぐ。

| type | 表示 | 例 |
|---|---|---|
| official | 自治体公式 | @ibaraki_Bousai 茨城県防災・危機管理課 |
| gov_related | 自治体関連施設 | @saitama_bousai 埼玉県防災学習センター |
| company | 民間企業 | @hokkaido_bousai 北海道支店 防災・鉄構 |
| organization | 団体 | @bousai_okinawa 日本防災士協会 沖縄県支部 |
| individual | 個人 | @shizuokabousai 静岡県出身40代男 |
| other_area | 別自治体（対象違い） | @yamagatabousai 山形**市**防災対策課 |
| unknown | 不明（採用しない） | |

判定は `tools/x_account_classify.py`（テスト: `tools/tests/test_x_account_classify.py`）。
実在確認は `tools/x_account_verify.py`。

**採用条件**（`prefectures` / `municipalities` に載せる条件）
1. type が official
2. 表示名に防災語（防災・災害・危機・避難）を含む＝防災専用アカウント
3. プロフィール本文が設定されている（本文が無く「N followers…」が返るものは休眠・なりすましを疑い保留）
4. 分類器の偽陽性を目視で除外（`excluded` に理由付きで記録）

### アプリ・配信への配線（2026-09-07）
- 配信: `tools/x_accounts_publish.py` が採用分（prefectures / municipalities / national_offices）だけを
  `site/v1/x_accounts.json` に書く（site/build.py から呼ぶ）。`candidates`・`excluded`・`unresolved_prefectures` は配信しない。
  type が official / national / gov_related 以外は配信時に落とす
- アプリ: `app/lib/data/x_accounts.dart`（取得・控え）、`app/lib/ui/x_accounts_screen.dart`（一覧。タップで外部Xを開く）。
  導線は災害速報タブ 気象警報タブ最下部と、カメラ詳細の所在地欄（所在県を先頭に表示）。種別ラベルは7言語のARBで併記

### 表記ゆれの注意
宮城県は `@miyagi_bosai`、三重県は `@bosaimie` のように **「bousai」ではなく「bosai」** の綴りがある。
探索パターンには両方を入れること（当初 bousai だけで14県を取りこぼした）。

### 除外した偽陽性
- `@yamanashi_bosai`「YBN 山梨防災ねっと放送【公式】」… 県ではなく放送プロジェクト
- `@saitama_bosai`「埼玉県消防防災課（関東防災連絡会）」… フォロワー10・本文なし。休眠の疑いで保留

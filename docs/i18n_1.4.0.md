# 多言語対応 1.4.0 — 実装記録

対象: `app/`（Flutter）。
前提調査: [research_2026-09-01/i18n_languages.md](research_2026-09-01/i18n_languages.md)

- **第1弾（2026-09-01）** … 基盤整備 ＋ `ja` / `ja_Hira` / `en`
- **第2弾（2026-09-01）** … 残った日本語文言のARB化 ＋ 简体中文 / 繁體中文 / 한국어 / Tiếng Việt の追加
  （ARBファイルは `app_zh.arb` / `app_zh_Hant.arb` / `app_ko.arb` / `app_vi.arb`。2章の注意書きを参照）

## 1. 対応言語（7ロケール）

| ロケール | 言語 | 自称表記 | 位置づけ |
|---|---|---|---|
| `ja` | 日本語 | 日本語 | 既定・**正文** |
| `ja_Hira` | やさしい日本語 | やさしい日本語 | 日本語・英語と**並列の1言語**として扱う（ユーザー決定事項）。BCP47 の `ja-Hira` |
| `en` | English | English | |
| `zh`（簡体字が基底） | 中国語（簡体字） | 简体中文 | 在留外国人1位（22.2%）・合成カバー率1位 |
| `zh_Hant` | 中国語（繁体字） | 繁體中文 | 訪日客では簡体字とほぼ同数（調査 4.4） |
| `ko` | 韓国語 | 한국어 | 訪日客1位（22.2%） |
| `vi` | ベトナム語 | Tiếng Việt | 在留外国人2位（16.5%・韓国の1.7倍） |

選定根拠は調査 4.3 / 4.4（上位4言語で合成カバー率 76.8%、`vi` を足して 79.7%）。

- **初回起動時は端末の言語設定から自動選択**する。強制の言語選択画面は出さない。
  - `ja` → 日本語 / `zh` → 簡体字（`zh-Hant` `zh-TW` `zh-HK` `zh-MO` は繁体字）/
    `ko` → 韓国語 / `vi` → ベトナム語 / **それ以外はすべて英語**
  - **やさしい日本語は自動選択しない**（本人が選ぶもの）
- **オンボーディング1画面目の上部に言語切替ボタンを常設**（押すと即時反映）。
  7言語に増えたため **横スクロールする `Row`** に変更した（`Wrap` で折り返すと
  オンボーディングの縦レイアウトが崩れるため）。選択中のチップが画面外にならないよう
  初回表示時にそこまでスクロールする。
- **設定画面の「言語 / Language」からいつでも切り替え可能**。選択は SharedPreferences
  （キー `app_language_v1`、値 `ja` / `ja-Hira` / `en` / `zh-Hans` / `zh-Hant` / `ko` / `vi`）に保存する。
  「端末の設定に合わせる」を選ぶと保存を消して自動判定に戻る。

### やさしい日本語の方針
- 漢字を減らす（ふりがなではなく**平易な語に置換**）
- 1文を短く
- 専門用語は言い換え＋（かっこ）で原語併記
  例: 氾濫危険情報 → 「川（かわ）が あふれる きけんが あります（洪水危険警報・レベル4）」
- **固有名詞（都道府県名など）は日本語表記のまま**（`ja` と同じ値を持たせている）

`AppLocalizationsJaHira` は `AppLocalizationsJa` を継承するため、**ARB にキーが無くても
自動的に日本語へフォールバック**する（テストで確認済み）。

## 2. ファイル構成

### l10n 基盤
| ファイル | 内容 |
|---|---|
| `app/l10n.yaml` | gen-l10n 設定（`arb-dir: lib/l10n` / `output-dir: lib/l10n/gen`） |
| `app/lib/l10n/app_ja.arb` | **テンプレート**（`@description` / `@placeholders` はここにのみ書く）。**503キー** |
| `app/lib/l10n/app_ja_Hira.arb` `app_en.arb` `app_zh.arb` `app_zh_Hant.arb` `app_ko.arb` `app_vi.arb` | 各言語（`@description` は持たせない） |
| `app/lib/l10n/gen/*` | `flutter gen-l10n` の生成物（analysis_options.yaml で除外済み） |
| `app/lib/l10n/l10n.dart` | `context.l10n` 糖衣構文 ＋ **キー→表示名の解決関数**（下記 3章） |
| `app/lib/data/locale_controller.dart` | `AppLanguage` enum と `LocaleController`（保存・復元・端末言語判定） |
| `app/lib/ui/language_switcher.dart` | `LanguageSwitcher`（オンボーディング用・横スクロール）/ `LanguageSettingTile`（設定画面用） |
| `app/ios/Runner/Info.plist` | `CFBundleLocalizations` = `ja, en, zh-Hans, zh-Hant, ko, vi` |

**簡体字のARBは `app_zh.arb`（`@@locale: zh`）である点に注意。**
`flutter gen-l10n` は「script/country 付きロケールしか無い言語」には**基底ロケールのARBを要求**し、
`app_zh_Hans.arb` + `app_zh_Hant.arb` だけだと
`Arb file for a fallback, zh, does not exist` で**生成そのものが止まる**。
そのため簡体字を基底（`zh`）に置き、繁体字を `zh_Hant` の派生にしている
（`AppLocalizationsZhHant extends AppLocalizationsZh`）。
`AppLanguage.zhHans.locale` も `const Locale('zh')` を返す。
`zh-Hans` / `zh-CN` / `zh-SG` の端末要求は `AppLanguage.chineseVariantOf()` でここへ寄せる。

## 3. BuildContext を持たない層の扱い

`lib/data/` `lib/util/` は `BuildContext` を持たないため、**キー（コード）だけを保持し、
表示名の解決は `lib/l10n/l10n.dart`（UI層）で行う**。第2弾で以下を追加した。

| 対象 | 変更 | 解決関数 |
|---|---|---|
| `data/hazard_layers.dart` | `title()` → `titleKey()`（`flood`/`landslide`/`tsunami`/`hightide`）。`landslideScale` の第1要素を区分キーに。`disclaimer` を削除 | `hazardLayerTitleOf()` / `landslideKindOf()` / `l10n.hazardDisclaimer` |
| `data/jma_layers.dart`（`RiskLayers`） | `title()`/`subtitle()` → `titleKey()`。`scale()` の第2要素を段階キー（`watch`/`caution`/`warning`/`danger`/`critical`）に。`attribution` は `JmaLayers.attribution` へ集約 | `riskLayerTitleOf()` / `riskLayerSubtitleOf()` / `riskLevelLabelOf()` |

## 4. 気象庁「多言語辞書」の利用

- 取得: <https://www.data.jma.go.jp/developer/jma_multilingual.xlsx>（**2026-03-26版・1.9MB・7,303行**）
- 掲載ページ: <https://www.data.jma.go.jp/developer/multilingual.html>
- ライセンス: 気象庁ホームページ利用規約 → **公共データ利用規約（第1.0版）＝CC BY 4.0互換。出典表示が必須**
- 収録14言語のうち **英語・中国語(簡体字)・中国語(繁体字)・韓国語・ベトナム語**の5列を使用
  （本アプリの対応言語すべてが辞書に含まれている）
- **2026-05-28の新体系（危険警報・レベル表記）にも対応済み**

### 確定訳の運用
xlsx から機械抽出した **108キー分の確定訳**（警報20 / 注意報17 / 震度4 / 地震通知しきい値3 /
都道府県47 / キキクル危険度5 / 避難場所の災害種別8 / 熱中症3 / 土石流1）を
言語ごとに**そのまま転記**した。翻訳担当は1文字も変更していない
（`test/i18n_test.dart` が `zh` / `zh_Hant` / `ko` / `vi` / `en` で実値を照合する）。

| 言語 | 辞書から確定 | 辞書から追加転記した用語 | 自訳（一般UI＋辞書に無い防災語） |
|---|---:|---:|---:|
| `en` | 108 | 第1弾で実施 | 約380 |
| `zh`（簡体字） | 108 | 約18 | 約380 |
| `zh_Hant` | 108 | 同等 | 同等 |
| `ko` | 108 | 約17 | 約380（うち防災語20件は辞書に項目が無く自訳） |
| `vi` | 108 | 約20 | 約375 |

辞書に項目が無く各言語で自訳した防災語（共通）: 地すべり / 急傾斜地 / 指定緊急避難場所 /
指定避難所 / ハザードマップ / 浸水想定区域 / 解析雨量 / アメダス / キキクル（音写＋説明を併記）/
防災拠点 / 給水拠点 / 防災備蓄倉庫 / 消防水利 / 消火栓 / 防火水槽 / 暑さ指数(WBGT) の各区分 /
地理院タイル。
ARB の `@description` と `lib/l10n/l10n.dart` の library doc comment に
「出典：気象庁。**自由訳しないこと**」を明記している。

### 辞書に無く合成した語（`ADAPT`。108キー中15キー）
辞書の語彙を組み合わせただけで、**訳語そのものは辞書から外れていない**。

| キー | 日本語 | 合成の根拠 |
|---|---|---|
| `warning09` `warning39` `advisory29` | 土砂災害警報 / 特別警報 / 注意報 | 辞書「土砂災害」＋「警報/特別警報/注意報」（2026新体系で追加された語） |
| `warning34` | 洪水特別警報 | 辞書「洪水」＋「特別警報」（同上） |
| `warning43` `warning48` `warning49` | 大雨/高潮/土砂災害 危険警報 | 辞書は `レベル４…危険警報` 形式。UIチップの一貫性のためレベル表記を除去 |

**アプリ内の出典表示**: 設定 →「出典・ライセンス」に
**「防災用語の翻訳について / 出典：気象庁ホームページ」**の項目があり、辞書のページを開ける
（`settingsJmaDictionary` / `settingsJmaDictionaryNote`）。

## 5. 翻訳しないもの

- **出典表記**（`XxxLayers.attribution` の `出典：…`、`Elevation.attribution` の `国土地理院`、
  カメラ台帳の `source.attribution`）。SPEC C5 と政府標準利用規約の出典記載条件に直結する
- カメラ名・運営者名・河川名/路線名（`data/cameras.json` 由来）
- `util/prefectures.dart` の `prefectureNames`（**コードの正準集合・気象庁データ突合用**。UI表示には使わない）
- `data/quake_intensity.dart` の正規化テーブル（`'5弱'→'5-'`。**表示ではなくデータ変換**）
- `data/shelter_layers.dart` の `defaultHazards`（配信JSONが日本語で送る正準集合。表示時に解決する）
- CSV/JSONのパース用リテラル（`'地点番号'` `'府県予報区'` `'解除'` `'なし'`、`jmaCityName()` の正規表現）
- 利用規約・プライバシーポリシー本文（Webページ・日本語のみ）
  → 設定画面に **「本文は日本語のみです（日本語を正文とします）」** を明示（`settingsLegalJapaneseOnly`）
- 不具合報告フォームの事前入力値（`detail_screen.dart`。開発者が読むもの）
- 免責文は翻訳するが、**日本語以外を表示中は「日本語版を正文とします」を併記する**
  （オンボーディング最終ページ・設定画面。`legalJapaneseAuthoritative`）

## 7. 言語を追加する手順

1. `app/lib/l10n/app_<locale>.arb` を作る。`app_ja.arb` の翻訳キー（現在503件）をすべて埋める。
   - `"@@locale"` をファイル名のロケールに合わせる
   - `@description` / `@placeholders` は**テンプレート `app_ja.arb` にのみ書く**（翻訳側には置かない）
   - **script / country 付きロケールを足すときは基底ロケールのARBも要る**
     （例: `pt_BR` を足すなら `app_pt.arb` が必要。無いと gen-l10n が止まる）
   - **防災用語は気象庁「多言語辞書」の該当言語列から機械的に転記**すること（自由訳禁止）。
     xlsx を落として `種別 / 情報種別等 / 日本語 / 各言語 / XMLコード表` の列を抜き、
     警報名・注意報名・震度・都道府県名・キキクル危険度・避難場所の災害種別・熱中症を埋める。
     辞書に無い語は `@description` に `ADAPT` と分かるように書く
2. `app/lib/data/locale_controller.dart` の `AppLanguage` に値を追加（`tag` と `locale`）。
   `fromLocale()` / `fromDeviceLocales()` の分岐も足す
3. `app/lib/ui/language_switcher.dart` の `languageDisplayName()` に**自称表記**を追加
4. `app/lib/main.dart` の `resolveAppLocale()` は `AppLanguage.fromLocale()` に委譲しているので変更不要
5. `app/ios/Runner/Info.plist` の `CFBundleLocalizations` に追加
6. `app/test/i18n_test.dart` の `_allLocales` と ARB グループの `files` / `expected` に追加
7. `flutter gen-l10n` → `dart analyze lib test` → `flutter test`
8. `flutter pub get` を実行した場合は **必ず `flutter build ios --config-only`**
   （CLAUDE.md の Package.swift platforms 問題）

### ARB を編集したら
`flutter gen-l10n` で `lib/l10n/gen/` を再生成する（`flutter run` / `flutter build` でも自動生成される）。

### 検証用スクリプト
キー欠落・空値・プレースホルダ不一致・気象庁確定訳との不一致は
`test/i18n_test.dart` の `group('ARB')` が全ロケール分を機械的に検査する。

## 9. 注意点

- **`warningLevelColor()` / `warningLevelRank()` はコードを受け取る**。
  以前は表示名に `'特別'` `'危険警報'` が含まれるかで判定していたため、
  翻訳すると色分けとソートが壊れる。ここは戻さないこと。
- 同様に **`RiskLayers.scale()` / `HazardLayers.landslideScale` の文字列はキーであって表示名ではない**。
  `riskLevelLabelOf()` / `landslideKindOf()` を通さずに描画すると英字キーが画面に出る。
- `ShelterLayers.defaultHazards` と `FacilityLayers.defaultKinds` は**配信JSONと突き合わせる日本語**。
  ここを翻訳すると避難場所の絞り込みが壊れる。
- `MaterialApp` は `ListenableBuilder` で包んでいる。言語を切り替えると
  MaterialApp 以下が作り直されるため、**開いているダイアログは閉じない**点に注意。
- `LanguageSwitcher` は7言語を横スクロールで並べる。言語を増やすときは

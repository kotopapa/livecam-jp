# 多言語対応 1.4.0 第1弾 — 実装記録

対象: `app/`（Flutter）。実装日 2026-09-01。
前提調査: [research_2026-09-01/i18n_languages.md](research_2026-09-01/i18n_languages.md)

## 1. 対応言語

| ロケール | 言語 | 位置づけ |
|---|---|---|
| `ja` | 日本語 | 既定・**正文** |
| `ja_Hira` | やさしい日本語 | 日本語・英語と**並列の1言語**として扱う（ユーザー決定事項）。BCP47 の `ja-Hira` |
| `en` | English | |

- **初回起動時は端末の言語設定から自動選択**する（日本語→`ja`、それ以外→`en`）。
  強制の言語選択画面は出さない。**やさしい日本語は自動選択しない**（本人が選ぶもの）。
- **オンボーディング1画面目の上部に言語切替ボタンを常設**（3つ並列・押すと即時反映）。
- **設定画面の「言語 / Language」からいつでも切り替え可能**。選択は SharedPreferences
  （キー `app_language_v1`、値 `ja` / `ja-Hira` / `en`）に保存する。
  「端末の設定に合わせる」を選ぶと保存を消して自動判定に戻る。

### やさしい日本語の方針
- 漢字を減らす（ふりがなではなく**平易な語に置換**）
- 1文を短く
- 専門用語は言い換え＋（かっこ）で原語併記
  例: 氾濫危険情報 → 「川（かわ）が あふれる きけんが あります（洪水危険警報・レベル4）」
- **固有名詞（都道府県名など）は日本語表記のまま**（`ja` と同じ値を持たせている）

`AppLocalizationsJaHira` は `AppLocalizationsJa` を継承するため、**ARB にキーが無くても
自動的に日本語へフォールバック**する（テストで確認済み）。

## 4. 気象庁「多言語辞書」の利用

- 取得: <https://www.data.jma.go.jp/developer/jma_multilingual.xlsx>（**2026-03-26版・1.9MB・7,302行**をダウンロードして確認済み）
- 掲載ページ: <https://www.data.jma.go.jp/developer/multilingual.html>
- ライセンス: 気象庁ホームページ利用規約 → **公共データ利用規約（第1.0版）＝CC BY 4.0互換。出典表示が必須**
- **2026-05-28の新体系（危険警報・レベル表記）にも対応済み**だった。実際に採用した対訳の例:

| コード | 日本語 | 英語（辞書の記載） |
|---|---|---|
| 04 | 洪水警報 | Flood Warning |
| 33 | 大雨特別警報 | Heavy Rain Emergency Warning |
| 43 | 大雨危険警報 | (Level 4) Urgent Warning (Heavy Rain) |
| 49 | 土砂災害危険警報 | (Level 4) Urgent Warning (Landslide) |
| — | 震度5弱 | Seismic intensity of 5-lower |
| — | 都道府県47件 | Tokyo Metropolis / Osaka Prefecture … （接尾辞を除いて採用） |

- **語順のみ既存訳に合わせて調整した語**（ARBの `@description` に `JMA_ADAPT` として明記）:
  危険警報4件は辞書が `Level 4 Urgent Warning (X)` 形式、特別警報は `X Emergency Warning` 形式で
  不統一なため、UIチップの一貫性のため `X Urgent Warning` に揃えた。
  2026新体系で追加された `34 洪水特別警報` / `39 土砂災害特別警報` / `09 土砂災害警報` / `29 土砂災害注意報`
  も同じ規則で命名した。**訳語そのものは辞書の語彙から外れていない。**
- **アプリ内の出典表示**: 設定 →「出典・ライセンス」に
  **「防災用語の翻訳について / 出典：気象庁ホームページ」**の項目を追加し、辞書のページを開けるようにした
  （`settingsJmaDictionary` / `settingsJmaDictionaryNote`）。
- ARB の `@description` にも「気象庁『気象情報等に関する多言語辞書』(2026-03-26版) の公式対訳。
  出典：気象庁。**自由訳しないこと**」と記録済み。`lib/l10n/l10n.dart` の library doc comment にも同じ注意書きがある。

## 5. 翻訳しないもの（調査 10.3 / 12.2 の方針どおり）

- カメラ名・運営者名・河川名/路線名・**出典表記**（`data/cameras.json` 由来。SPEC C5 と政府標準利用規約の出典記載条件に直結）
- `Elevation.attribution`（国土地理院）などのデータセット出典表記
- 利用規約・プライバシーポリシー本文（Webページ・日本語のみ）
  → 設定画面に **「本文は日本語のみです（日本語を正文とします）」** を明示（`settingsLegalJapaneseOnly`）
- 免責文は翻訳するが、**日本語以外を表示中は「日本語版を正文とします」を併記**する
  （オンボーディング最終ページ・設定画面。`legalJapaneseAuthoritative`）
- 不具合報告フォームの事前入力値（開発者が読むもの）

## 7. 言語を追加する手順

1. `app/lib/l10n/app_<locale>.arb` を作る。`app_ja.arb` のキーをすべて埋める
   （`@description` / `@placeholders` はテンプレート `app_ja.arb` にのみ書く）。
   防災用語は**気象庁「多言語辞書」の該当言語列から機械的に転記**すること（自由訳禁止）。
2. `app/lib/data/locale_controller.dart` の `AppLanguage` に値を追加（`tag` と `locale`）。
3. `app/lib/ui/language_switcher.dart` の `languageDisplayName()` に自称表記を追加。
4. `app/lib/main.dart` の `resolveAppLocale()` の分岐を追加。
5. `app/ios/Runner/Info.plist` の `CFBundleLocalizations` に追加。
6. `flutter gen-l10n` → `dart analyze lib test` → `flutter test`。
   `test/i18n_test.dart` の「3ロケールでキーの欠落が無い」テストに新ロケールを足す。
7. `flutter pub get` を実行した場合は **必ず `flutter build ios --config-only`**
   （CLAUDE.md の Package.swift platforms 問題）。

### ARB を編集したら
`flutter gen-l10n` で `lib/l10n/gen/` を再生成する（`flutter run` / `flutter build` でも自動生成される）。

## 9. 注意点

- **`warningLevelColor()` / `warningLevelRank()` はコードを受け取る**ようになった。
  以前は表示名に `'特別'` `'危険警報'` が含まれるかで判定していたため、
  翻訳すると色分けとソートが壊れる。ここは戻さないこと。
- `MaterialApp` は `ListenableBuilder` で包んでいる。言語を切り替えると
  MaterialApp 以下が作り直されるため、**タブの選択状態などの一時状態はリセットされない**
  （`HomeShell` の State は保持される）が、開いているダイアログは閉じない点に注意。
- `app/ios/LiveCamWidget/`（ホーム画面ウィジェット）は**未対応・日本語のまま**（1.3.0 のまま）。
- プッシュ通知（`tools/bosai_notify.py`）はサーバー側で日本語生成のまま。多言語化は
  FCMトピックの言語軸分割が必要で別工数（調査 10.5 / CLAUDE.md のレート制限の落とし穴）。
- App Store Connect のストアリスティング（`docs/appstore_metadata.md`）は未対応。
